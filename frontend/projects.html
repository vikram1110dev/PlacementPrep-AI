Real-time Chat App

Build a fully functional MERN stack chat application from scratch.

Project Progress
65% Completed
5/8 Milestones Deadline: Oct 15
Project Overview
Objective

To build a scalable real-time chat application where users can create rooms, send messages instantly, and see online status. This project demonstrates proficiency in WebSockets, state management, and NoSQL databases.

Learning Outcomes
  • Understanding WebSocket protocol and bidirectional communication.
  • Managing complex React state with Redux/Context API.
  • Designing MongoDB schemas for users, chats, and messages.
  • Implementing JWT based authentication.
Recommended Folder Structure
backend/ ├── controllers/ ├── models/ │ ├── userModel.js │ └── messageModel.js ├── routes/ ├── config/ │ └── db.js └── server.js frontend/ ├── src/ │ ├── components/ │ ├── pages/ │ ├── context/ │ └── App.js
Development Milestones
1. Environment Setup & DB Design

Initialize Node.js and React apps. Design MongoDB schemas.

2. Authentication APIs

Implement Register/Login with JWT and bcrypt.

3. Socket.io Integration

Setup WebSocket connection. Handle connect, disconnect, and broadcast events.

4. Frontend UI & State

Build chat interface, integrate Context API, and connect to backend.

5. Deployment

Deploy backend to Render/Heroku and frontend to Vercel/Netlify.
